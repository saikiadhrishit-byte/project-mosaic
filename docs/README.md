# Nysor Documentation

Nysor is an experimental architecture for composing software systems from reusable Blocks. The initial prototype uses small arithmetic graphs to test compiler and runtime ideas. It is not yet a complete game engine or package ecosystem.

## Status Vocabulary

- **Current Prototype** means functionality confirmed in the repository.
- **Architecture Direction** means a direction the project intends to pursue.
- **Proposal / Future Work** means an idea that remains experimental or unresolved.
